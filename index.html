pitchsense-0ydl.onrender.com Project 01
Machine Learning / Full-Stack

PitchSense

A full-stack soccer match predictor. Logistic Regression and Gradient Boosting models trained on 25,000+ European matches with a time-based split, plus a live engine that re-runs 10,000 Monte Carlo simulations as the match unfolds.

  • 50.3% test accuracy vs. a 44.2% always-home baseline, within 2 points of Bet365 implied odds.
  • Live win/draw/loss probabilities with clutch-moment detection, streamed over WebSockets.
  • Dockerized, tested in GitHub Actions, and deployed on Render.

net-pulse Project 02
Go / Systems & Networking

Net-Pulse

A Go + React monitoring tool shipped as one binary. It samples 6 system metrics every 2 seconds, probes up to 25 targets with DNS, TCP, verified TLS, and HTTP checks, and tells you whether a problem is your PC or the network.

  • 16-rule alert engine across 3 severity levels, using sustain periods, hysteresis, and cooldowns.
  • Per-target uptime %, certificate-expiry warnings at 21 and 7 days, and 7 days of history in SQLite.
  • 267 automated tests with race detection on Windows + Linux CI; releases auto-build for 3 platforms.

cloudsentry Project 03
Cloud Security / AI

CloudSentry

A read-only AWS security scanner. 12 deterministic checks across IAM, S3, EC2, CloudTrail, and root account settings decide every finding; Amazon Bedrock only explains them in plain English.

  • Fixed severity rules the AI can't change, with safe fallbacks when Bedrock is unavailable.
  • $0 serverless deployment (CloudFront, Lambda, private S3) as a CloudFormation template with least-privilege IAM.
  • 140+ tests (pytest, Vitest) and a GitHub Actions pipeline that tests, builds, and lints on every push.
